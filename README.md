# Kaze Nick Alvin — Portfolio

A three-page, responsive static portfolio built with HTML and CSS.

## Files
- `index.html` — Home page
- `about.html` — About Me page
- `contact.html` — Contact page
- `style.css` — Shared styling for all pages

## Preview locally
Open `index.html` in a web browser. Keep all four files in the same folder.

## Before publishing
1. Check the project links on the Home page and replace the sample GitHub links with the exact repositories.
2. Add a public professional email address on `contact.html` if you want one displayed.
3. Review all personal details before publishing.

## Publish
Upload/commit all four files to the desired GitHub repository. If deploying to the existing PythonAnywhere site, pull the changes on the server only when you're ready to publish them.
